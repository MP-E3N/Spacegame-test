**Schnittstelle (vorab, Projektleitung):**
```js
// src/sim/form/generator.js (Schiffbauer) — rein: kein three, kein DOM, kein Math.random (zufall aus src/sim/zufall.js)
export const KLASSEN = {            // Grundwerte je Klasse; die Regler wirken relativ dazu
  korvette: { name: 'Korvette', laenge: [60, 110], … },
  fregatte: { name: 'Fregatte', laenge: [120, 200], … },
  traeger:  { name: 'Träger',   laenge: [220, 340], … },
};
export const GENERATOR_REGLER = {   // je { name, min, max, schritt, standard, tipp } — die Seite baut daraus die Regler
  laenge, breite, kantigkeit, aufbauten, geschuetze, triebwerke
};
export function standardEinstellung(klasse)  // → { seed, klasse, laenge, breite, kantigkeit, aufbauten, geschuetze, triebwerke }
export function generiere(einst)              // → rohe Form { name, version, art: 'rumpf', koerper, andock: [], bauteile }
                                              //   gleiche einst → bitgleiche Form (JSON gleich); normalisiere(form) ändert nichts Wesentliches
```
- Körper und Bauteile nutzen nur das Datenmodell aus `form.js` (Spanten, Spiegel `['x']`, op plus/minus, mat) und die
  Katalog-Schlüssel aus `bauteile.js` (`pdc`, `flak`, `schwer`, `triebwerk_s/m/l`, `steuer`).
- **Flugtauglich per Bau:** alles spiegelsymmetrisch zu x = 0; Haupttriebwerke an der flachen Heckfläche
  (n `[0,0,−1]`) auf der Schwerpunkt-Höhe (Schwerpunkt mit `massenwerte` aus `flug.js` nachrechnen, dann setzen);
  Manöverdüsen vorn + hinten; Geschütze nur auf ebenen Ober-/Unterseiten, Fuß genau auf der Fläche.
- **Name** aus Klasse + Seed (z. B. „Korvette 4711“), damit Speichern/Probeflug sofort gehen.

## Frühwarnung
- **Schiffbauer:** Triebwerks-Höhe = Schwerpunkt OHNE Haupttriebwerke (Fixpunkt), Heck-Spant muss c.y ± r decken;
  p.z = erster Spant des Hauptrumpfs (Kappe eben), |x| + r ≤ b/2 − Fase-Einzug, nichts steht hinter dem Heck vor.
  Türme: Ring 2,7·s muss ganz auf ebener Oberseite liegen (ueber_kante/schraeg), Säule frei (im_rumpf), Abstand
  ≥ 2,7·(sa+sb) (zu_dicht), für 0 Warnungen ≥ 9,1·(sa+sb) (rohre_kreuzen); Turm auf x = 0 nur ohne Spiegel.
  Überlappende Plus-Körper zählen doppelt (Schwerpunkt bleibt stimmig), Minus ganz innen. dreh nur 0/±90°. CSG: 30 Körper
  ≈ 90 ms, jeder Minus-Satz ein Schritt; T-Stöße → Seitenblöcke 0,5–1 m einsetzen. Je Stufe eigener Zufallsstrom.
  Aufbau: Hauptrumpf = EIN Körper mit 6–14 Spanten (Abschnitte „eben“ = Turmplätze / „Stufe“), Seitenblöcke gespiegelt
  eingesetzt, Kiel unten, gepanzerter Kommandoblock + Antennen, flache Minus-Rillen an den Flanken, Bauteile, Selbsttest.
- **Prüfer:** ~400 Formen (3 Klassen × 40 Seeds + Regler-Extreme + Ecken), 0 Fehler, Türme fallen nicht still weg,
  eigene Symmetrie-/Heck-/Überlapp-Prüfungen, schlechte Eingaben klemmen, Regler-Wirkung ≥ 80 % der Seeds, Vielfalt,
  Laufzeit. Stolperfallen: normalisiere kürzt still (64/96), rundet p auf 1e-6, art fehlt → 'anbau'; sin/cos nur bei
  90°-Vielfachen; Seed-Wirkung über `>>> 0` → Name mit effektivem Seed; Favoriten veralten bei Generator-Änderung.

## Entscheidungen
1. **Rückgabe:** `generiere(einst)` gibt eine bereits **normalisierte** Form zurück (`normalisiere(f)` ändert nichts,
   JSON gleich), `art: 'rumpf'`, `andock: []`, Name „<Klasse> <Seed>“ mit effektivem Seed. Ungültige Eingaben werden
   geklemmt (unbekannte Klasse → fregatte, Seed → ganze Zahl 1…999 999), nie werfen. Export auch `GENERATOR_VERSION = 1`.
2. **Regler** (Tabelle `GENERATOR_REGLER`, je `{ name, min, max, schritt, standard, tipp, text(v, einst) }` — `text`
   liefert die Anzeige, z. B. Meter je Klasse):
   - `laenge` 0…1 → Längenbereich der Klasse (Anzeige in m) · `breite` 0,7…1,3 × Grundbreite (Standard 1)
   - `kantigkeit` 0…1: **höher = kantiger** → Fase kleiner (≈ 0,45 → 0,05), mehr Stufen; bei 0 darf eine leichte
     Rundung (≤ 0,2) dazukommen, sonst rundung 0. Messgröße Prüfer: mittlere Fase ↓, Stufenzahl ≥.
   - `aufbauten` 0…1 → Zahl der Aufbauten, Antennen, Rillen · `geschuetze` 0…1 → Turmdichte der Klasse (0 = keine Türme)
   - `triebwerke` = **Anzahl 1…5** (Nutzer denkt in Stück); die Größe kommt aus der Klasse (Korvette S/M, Fregatte M/L,
     Träger L) und wird automatisch eine Stufe größer, wenn sonst `zu_schwach`. Ungerade → eins auf x = 0 ohne Spiegel.
3. **Klassen/Budget** wie Schiffbauer-Tabelle (Korvette 60–110 m, Fregatte 120–200 m, Träger 220–340 m flach mit
   Hangar-Blöcken an der Hülle). Körper-Einträge ≤ 28, ≤ 40 inkl. Spiegelkopien, ≤ 5 Minus; Bauteile ≤ 48.
4. **Selbsttest in generiere** erlaubt (pruefeSchiff aus bauteile.js, massenwerte aus flug.js, TURM/GESCHUETZE/ANTRIEBE);
   bei Fehler deterministisch nachbessern (Turm weg, Triebwerk größer), höchstens 2 Durchläufe.
5. **Ziele:** 0 Fehler bei 100 % der Formen; Schiffbauer zielt auf ≤ 1 % mit Warnungen, Prüfer-Schwelle 5 % (weich:
   rohre_kreuzen, kein_schussfeld, ueber_kante, schraeg; immer erlaubt: kein_punkt). generiere ≤ 20 ms im Mittel,
   ≤ 50 ms höchstens; Verschweißen ≤ 150 ms im Browser (misst die Projektleitung).
6. **Teilströme:** je Stufe ein eigener Zufallsstrom — `aufbauten` ändern lässt den Hauptrumpf bitgleich.
7. **Triebwerksgehäuse:** die Sim prüft keine Tiefe; das Gehäuse zeichnet `src/grafik/form/schiff.js` (Schiffbauer,
   R19) — dort nachsehen, hinter dem Heck darf nichts vorstehen.
8. **Favoriten** (Seite, Projektleitung) speichern `einst` + `GENERATOR_VERSION`; bei anderer Version Hinweis
   „älterer Generator — kann anders aussehen“. Regler-Ziehen: ein Rückgängig-Schritt, Verschweißen wie immer 250 ms
   nach der letzten Änderung.
